# Reproducibility Checklist

- [x] Random seed fixed.
- [x] Synthetic generator versioned.
- [x] Chronological train/test split.
- [x] Training-only preprocessing.
- [x] Comparable baselines.
- [x] Explicit parameters.
- [x] Pinned requirements.
- [x] Dockerfile.
- [x] DVC stages and lock file.
- [x] Machine-readable metrics and predictions.
- [x] Serialized model.
- [x] SHA-256 artifact manifest.
- [x] Synthetic status disclosed.
- [ ] Restricted real-data hash.
- [ ] Genuine MLflow runs.
- [ ] Independent rerun by another researcher.
